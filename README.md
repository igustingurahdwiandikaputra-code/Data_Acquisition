# Deskripsi
Repository ini dibuat untuk memenuhi tugas mata kuliah Akuisisi dan Manajemen Data. Proyek ini berisi penerapan konsep data acquisition dan data management serta pemetaan Data Science Lifecycle yang terdiri dari Acquisition, Storage, Cleaning, Transformation, Analysis, dan Delivery.

# Mengapa reproducibility penting dalam akuisisi data, sertakan satu contoh kasus nyata.
Reproducibility penting dalam proses akuisisi data karena memastikan bahwa proses memperoleh dan mengolah data dapat dilakukan kembali oleh orang lain dengan langkah dan hasil yang konsisten. Dalam proyek data, sumber data, kode, library, struktur folder, serta tahapan pengolahan perlu didokumentasikan dengan baik agar prosesnya dapat ditelusuri. Tanpa reproducibility, hasil analisis sulit diverifikasi dan kesalahan yang terjadi selama proses akuisisi akan sulit ditemukan. Penggunaan Jupyter Notebook, Git, README, serta struktur folder yang konsisten dapat membantu menjaga reproducibility. Contohnya adalah pengambilan data melalui API. Jika seorang mahasiswa hanya menyimpan hasil akhir dataset tanpa mencatat alamat API, waktu pengambilan, kode Python, dan proses pengolahannya, mahasiswa lain akan kesulitan mendapatkan kembali dataset dengan proses yang sama. Sebaliknya, apabila seluruh proses dicatat dalam notebook dan perubahan kode disimpan menggunakan Git, proses tersebut dapat dijalankan kembali dan diperiksa. Dalam kasus nyata, reproducibility sangat penting pada penelitian berbasis data, karena peneliti lain perlu dapat mengulang proses pengumpulan dan pengolahan data untuk memverifikasi hasil penelitian. Oleh karena itu, reproducibility menjadi bagian penting dalam menjaga transparansi, konsistensi, dan kepercayaan terhadap hasil analisis data.
